# Student Profile Dashboard

A simple and interactive Student Profile Dashboard built using HTML and CSS.

This project focuses on creating a clean, organized interface to display student profile information through a web-based layout.

## Technologies Used

- HTML5 – For structuring the webpage.
- CSS3 – For styling and designing the dashboard.

## Project Structure

```text
student-profile-dashboard/
│
├── flex.html
├── flex.css
├── i.jpeg
├── profile.png
└── README.md
```

## Features

- Student profile interface.
- Structured webpage layout.
- Custom CSS styling.
- Image integration.
- Responsive design elements.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `flex.html` in your web browser.
4. Explore the Student Profile Dashboard!
